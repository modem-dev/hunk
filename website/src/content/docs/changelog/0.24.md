October 13, 2026 – October 19, 2026 · 4 releases

Hunk 0.24 adds complete-file and directory browsing, a live workspace status view, npm-installed extensions, shell completions, and pane-aware automatic diff layout, while moving syntax highlighting off the review's main thread by default.

New to Hunk? Use the default installer. It verifies downloads when release checksums and local tooling are available, and warns otherwise:

```sh
curl -fsSL https://hunk.dev/install.sh | sh
```

Already on Hunk 0.20 or newer with the default install script, npm, or Homebrew? Move to this release with Hunk's canonical update command:

```sh
hunk update
```

On an older Hunk release, update once through the installer or package manager that installed it, then use `hunk update`. mise, Nix, source, and custom-directory installs remain owned by their own update workflows. This is the current release; see [all install options](/docs/start/install/).

### 0.24.1

Unreleased

#### Patch Changes

- Upgrade the bundled Bun runtime to 1.4.4 so Hunk's own HTTPS requests (GitHub review via `hunk gh`, extension fetches) reject certificates issued by the compromised eMudhra intermediate CAs. ([#1218](https://github.com/modem-dev/hunk/pull/1218))
- Build the Nix package with the same script as the npm and GitHub release binaries, so Nix installs always ship the same entrypoints and x64 baseline runtime policy. ([#1214](https://github.com/modem-dev/hunk/pull/1214))
- Fix missing syntax highlighting in Nix-built binaries by bundling the highlighting worker. ([#1211](https://github.com/modem-dev/hunk/pull/1211))
- `n` / `N` now stop at every search match, including later matches in the same hunk or on the same line, in on-screen order: top to bottom in unified view and row by row, old side first, in split view. Extension API 32 adds `ctx.selection.layout`, the resolved `split` or `unified` layout; TypeScript authors constructing `ExtensionReviewSelection` must add the field. A new `/` search now starts at the cursor line instead of skipping the selected hunk. ([#1212](https://github.com/modem-dev/hunk/pull/1212))

### 0.24.0

October 19, 2026

#### Minor Changes

- Add an `auto_split_min_width` config setting with a default of 160 available diff columns, accounting for side panes and outer padding so auto layout switches between unified and split as panes open, close, or resize. ([#1170](https://github.com/modem-dev/hunk/pull/1170))
- Reveal left and right extension panes independently and add `ctx.panes.isVisible()` so guide toggles leave the files pane's state untouched. ([#1171](https://github.com/modem-dev/hunk/pull/1171))
- Add `hunk open` to view complete syntax-highlighted files and browse directories with lazy loading, live refresh, and keyboard/mouse navigation. ([#1148](https://github.com/modem-dev/hunk/pull/1148))
- Add `hunk skill show [name]` and publish pointer skills installable with `npx skills add modem-dev/hunk -g --skill hunk-review` or `--skill hunk-extensions`, delegating agent installation to the skills CLI while loading version-matched instructions from the installed Hunk binary. ([#1167](https://github.com/modem-dev/hunk/pull/1167))
- Support scoped npm packages, versions, ranges, and tags in `hunk extension install` and the shared list/update/remove workflow while preserving Git installs and blocking npm lifecycle scripts. ([#1162](https://github.com/modem-dev/hunk/pull/1162))
- Add a `scroll_off` setting (and `--scroll-off <rows>` flag) that defaults to keeping five rows of context around the current line while stepping through a diff, like Vim's `scrolloff`, with `scroll_off = 0` or `--scroll-off 0` restoring edge-only scrolling. ([#1109](https://github.com/modem-dev/hunk/pull/1109))
- Make the note composer save shortcut remappable via `hunk.review.saveNote` (default `ctrl+s`). ([#962](https://github.com/modem-dev/hunk/pull/962))
- Add `hunk completion bash` and `hunk completion zsh` to print shell completion scripts for commands, flags, and enumerated flag values. ([#1157](https://github.com/modem-dev/hunk/pull/1157))
- Add a live read-only workspace status view with sibling inspection, shared-theme navigation into Log and full diff reviews, indented tracked/untracked groups with readable theme-colored staging facts and independent ten-file expansion, clearly separated sibling worktrees, and static or versioned JSON output. ([#1067](https://github.com/modem-dev/hunk/pull/1067))
- Add extension-owned, generation-scoped presentation filters for selecting runtime files and hunks without changing canonical review state. ([#1118](https://github.com/modem-dev/hunk/pull/1118))
- Syntax highlighting now runs in the worker by default, and the worker starts compiling the review's grammars during startup, so the first key after the review appears is no longer blocked by highlighting. `--fast` is accepted as a no-op and will be removed in a later release; Windows compiled binaries and custom themes with `syntax_scopes` keep highlighting inline. ([#1105](https://github.com/modem-dev/hunk/pull/1105))

- Fill initial document and tree viewports without requiring scrolling when native layout temporarily reports a negative scroll position. ([#1148](https://github.com/modem-dev/hunk/pull/1148))

- Reduce memory use in large reviews by keeping copy-selection row content lazy during keyboard navigation. ([#1202](https://github.com/modem-dev/hunk/pull/1202))
- Keep the file filter focused in pager mode when files reappear after a filter matches no files. ([#1161](https://github.com/modem-dev/hunk/pull/1161))
- Allow bounded cold PowerShell startup time when locating the Windows account's document save namespace. Account lookup failures still refuse writeback and preserve recovery copies. ([#1148](https://github.com/modem-dev/hunk/pull/1148))
- Fix plain-text Git pager output being truncated or failing with EPIPE when stdout is piped. ([#1112](https://github.com/modem-dev/hunk/pull/1112))
- Name the repository in every Jujutsu source-read diagnostic. A missing `jj` binary and an unreadable `jj` stream now log the repo path beside the revision and file, as a failed `jj file show` already did. ([#1146](https://github.com/modem-dev/hunk/pull/1146))
