November 11, 2026 · 1 release

Hunk 0.25 adds inline before-and-after image previews, clearer active-pane focus, GitHub Enterprise Cloud reviews, and a preview-and-confirm feedback form, while making patch parsing and everyday review interactions more resilient.

New to Hunk? Use the default installer. It verifies downloads when release checksums and local tooling are available, and warns otherwise:

```sh
curl -fsSL https://hunk.dev/install.sh | sh
```

Already on Hunk 0.20 or newer with the default install script, npm, or Homebrew? Move to this release with Hunk's canonical update command:

```sh
hunk update
```

On an older Hunk release, update once through the installer or package manager that installed it, then use `hunk update`. mise, Nix, source, and custom-directory installs remain owned by their own update workflows. This is the current release; see [all install options](/docs/start/install/).

### 0.25.0

November 11, 2026

#### Minor Changes

- Highlight active built-in and extension panes with accent-weighted separators. ([#993](https://github.com/modem-dev/hunk/pull/993))
- Add `hunk feedback` and Help → Send feedback, which send a message to the Hunk team only after showing exactly what is sent and asking you to confirm. ([#1262](https://github.com/modem-dev/hunk/pull/1262))
- `hunk gh pr|commit|compare` now works with GitHub Enterprise Cloud (`<tenant>.ghe.com`). Pull-request and commit URLs and the local `origin` remote select the host automatically; `--repo host/owner/repo` and `GH_HOST` select it for short forms. ([#1264](https://github.com/modem-dev/hunk/pull/1264))
- Preview changed PNG, JPEG, GIF, and WebP files inline with `i`, drawing the before and after images where "Binary file skipped" appears, and let extensions read exact file bytes through `input.readBytes` and VCS `readFileBytes` (extension API 33). ([#1210](https://github.com/modem-dev/hunk/pull/1210))
- Remove the `--fast` flag, which has been a no-op since 0.24.0 made worker highlighting the default. Drop `--fast` from shell aliases, scripts, and pager configs such as Git's `core.pager` or LazyGit; Hunk now rejects it as an unknown option or command. ([#1207](https://github.com/modem-dev/hunk/pull/1207))

#### Patch Changes

- Text typed in the same input chunk as Tab now fills the file filter instead of triggering global shortcuts.
- Show UTC commit dates in `hunk log` the same way on every Git version, instead of `+00:00` on older Git releases. ([#1247](https://github.com/modem-dev/hunk/pull/1247))
- Keep readable files in a review when another file has an unparseable diff, and preserve patch line counts when stripping terminal control sequences from binary-looking content. ([#975](https://github.com/modem-dev/hunk/pull/975))
- Numpad navigation keys such as PgUp and PgDn now trigger the same shortcuts as their main-keyboard counterparts. ([#1225](https://github.com/modem-dev/hunk/pull/1225))
- Fall back to the bundled Bun runtime when the npm launcher cannot start the prebuilt binary, such as when Windows Application Control blocks it.
- Let deprecated `registerSidebarView` components sort or extend their `files` array without crashing the sidebar. ([#1267](https://github.com/modem-dev/hunk/pull/1267))
- Keep an open note draft accepting input when a live agent reply lands in the same thread.
- Pressing `c` while a note card is selected now opens the new draft on that note's line, below its thread, instead of on the first added line of the hunk. ([#1263](https://github.com/modem-dev/hunk/pull/1263))
- Render large unwrapped diffs within the size limits without exhausting native text buffers during startup. ([#1241](https://github.com/modem-dev/hunk/pull/1241))
- Faster, more forgiving patch parsing. Quoted `diff --git` filenames with escaped characters (spaces, non-ASCII) now decode to the real file name, and hunks whose declared line counts disagree with their body are repaired instead of dropped. Syntax highlighting is unchanged. ([#1184](https://github.com/modem-dev/hunk/pull/1184))
- Compact menu-bar labels before truncating the current review title on narrow terminals. ([#1094](https://github.com/modem-dev/hunk/pull/1094))
- Upgrade `shell-quote` to 1.12.0 and `zod` to 4.6.x. This clears GHSA-pqg4-j6r4-53mv (critical, command injection through `quote()` when a line terminator follows a `{ comment }` token, fixed in 1.11.0) and GHSA-mrhx-c7xc-m3w5 (high, memory exhaustion while validating oversized constrained collections, fixed in 4.6.6). Both advisories reach every `hunkdiff` install through the published dependencies. ([#1256](https://github.com/modem-dev/hunk/pull/1256))
- Keep the unchanged-lines gap rows when a presentation scope retains every hunk of a file, so expand (`z`) and gap clicks keep working inside that scope. ([#1239](https://github.com/modem-dev/hunk/pull/1239))
- Pointer skills installed with `npx skills add modem-dev/hunk` now fall back to `hunk skill path` when the installed Hunk predates `hunk skill show`.
- Load symlinked extension files with Hunk's React and JSX runtime so their panes and hooks work like copied files. ([#1240](https://github.com/modem-dev/hunk/pull/1240))
- Require Hunk 0.24.x or newer in agent skill pointers instead of falling back to instructions for older versions. ([#1271](https://github.com/modem-dev/hunk/pull/1271))
- Keep portable watch mode observing changes after a missing review directory is created or recreated. ([#1269](https://github.com/modem-dev/hunk/pull/1269))
- Report that Windows ARM64 is not supported by the current bundled runtime instead of crashing with a low-context Bun FFI error. ([#1197](https://github.com/modem-dev/hunk/pull/1197))
